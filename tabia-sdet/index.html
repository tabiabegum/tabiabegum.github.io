Backend engineering

Services built for the Sirius platform

FlintLab's Sirius platform gives engineering teams on-demand access to real and virtual devices for automated testing, through a web interface, a CLI and APIs. These are the services I designed, built and tested for it.

01 · Container Management Service

On-demand test environments connected to real devices

Challenge: running device automation required installing and configuring Appium and test sources locally.

Solution: pre-configured containers attached to target devices, with a browser terminal, script execution, pause and delete controls, cross-region creation and downloadable reports.

Outcome: a ready environment in 8 seconds, with no local setup.

Python, FastAPI, Podman, PostgreSQL, Redis, Traefik, WebSockets, Dapr

End-to-end ownerWatch demo

02 · Nexus Device Enrollment

Automated device onboarding

Challenge: device settings reset after every reboot or disconnect, so lab engineers reconfigured them manually.

Solution: an enrollment pipeline that authenticates each Android or iOS device on connection, applies base, OEM and customer configurations, then verifies the result.

Outcome: devices start every session in a consistent, verified state.

Python, FastAPI, gRPC, Android DPC, ADB, Redis, PostgreSQL, Dapr

Primary owner: architecture, development, testing

03 · Flint CLI

Command-line access to remote devices

Solution: a cross-platform CLI for Windows, macOS and Linux to manage remote devices and run tests from a local terminal.

Details: token-based authentication with 24-hour sessions and automatic version updates.

Python, WebSockets, PostgreSQL, ADB, pipx

End-to-end ownerWatch demo

04 · Virtual Device Management

API latency reduced from 300 ms to 18 ms

Built the Genymotion SaaS integration behind the FlintLab and Genymotion partnership, provisioning Android emulators inside Sirius without a separate sign-in.

05 · Emulator Device Service

Isolated emulator sessions

Stateless, Redis-backed service for APK installation and mock locations, with strict per-device session isolation.

Documentation

Authored the PRDs and technical design documents for CMS and EDS, led lifecycle design for VDMS, and contributed the WebSocket streaming design for Flint CLI.
